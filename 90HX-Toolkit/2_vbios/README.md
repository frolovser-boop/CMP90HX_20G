# 2. VBIOS: дамп, правка (BCT), прошивка

Инструменты для работы с VBIOS CMP 90HX — в первую очередь для 20GB-мода
(полная процедура: `MyCMP90/docs/20GB_PROCEDURE.md`).

## Состав

| Файл | Что это | Когда использовать |
| :--- | :--- | :--- |
| `OMGVflash.zip` | Обёртка над nvflash для работы с VBIOS без части проверок (Windows) | Дамп/прошивка VBIOS из Windows на хосте, где карта видна |
| `nvflashk-main.zip` | nvflashk — форк nvflash с ослабленными проверками соответствия платы (исходники/скрипты, 6.6 КБ) | Прошивка «чужих» BCT/образов, когда штатный nvflash отказывается |
| (Linux) `nvflash` 9.5 МБ | Свежий Linux-флешер из `../455.219/455.219/nvflash` (вне репозитория) | Из TinyLinux/сервера |

## Правила безопасности

1. **Сначала дамп.** Сохранить текущий VBIOS дважды, на разные носители, записать
   контрольные суммы. Без дампа — никаких экспериментов.
2. Изменения только в дампе: для 20GB-мода — импорт секции **BCT** из инженерного
   VBIOS RTX 3080 20GB через Ampere BIOS Editor (NOT прошивка чужого VBIOS целиком:
   кросс-прошивка RTX 3080 Manli давала `GFW_BOOT 0x55` = memory training failed).
3. Прошивка модифицированного дампа → во внешнюю SPI-flash программатором или
   через nvflashk/OMGVflash с работающей карты.
4. Карта без видеовыходов: прошивать на хосте с другим primary-GPU.
5. После прошивки 20GB: до BCT-валидации не включать ReBAR (селекторы 8/9).

## Порядок для 20GB-мода (кратко)

```text
дамп стока → замена чипов 8Gb→16Gb → страпы RAMCFG 16Gb →
BCT от RTX 3080 20GB в дамп → прошивка → загрузка TinyLinux (папка 1) →
mods -test 275 → патч драйвера с динамическим WPR2 → nvidia-smi = 20480 MiB
```

Диагностика после пайки — [`../1_usb_diagnostics/`](../1_usb_diagnostics/README.md),
карты чипов — [`../4_memory_maps/`](../4_memory_maps/README.md).
