## Универсальные предостережения

1. **Диагностика MODS/MATS требует отсутствия ОС-драйвера NVIDIA** — запуск только
   с загрузочной флешки (или выгрузив `nvidia.ko`/`nouveau`).
2. **CMP 90HX не имеет видеовыходов** → в MODS это всегда сценарий «secondary GPU»:
   хост с iGPU, `modsinit` → `mods` / `mats -n 1`.
3. **Secure Boot выключен** — нужно и для диагностической флешки, и для анлока.
4. VBIOS-операции: сначала дамп (×2 копии), потом любые изменения; карта без
   видеовыходов прошивается на работающем хосте с другим GPU либо программатором.
5. Все архивы/образы — из неофициальных источников; используйте на изолированном
   стенде. Целостность проверяйте по `SHA256SUMS.txt` этого набора.
