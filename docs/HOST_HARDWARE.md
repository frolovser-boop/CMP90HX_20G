# Подбор хоста для ИИ-машины на CMP 90HX (бюджетно, 2026-11)

> Требования выведены из всего исследования проекта: диагностика MODS требует
> Legacy-загрузки и дисплея не с тестируемой карты; V67-payload живёт >4 ГБ
> (Above 4G); стоковые карты тренируются x4 (допайка конденсаторов — отдельная
> работа); райзеры ломают MODS/ширину; 2×8-pin питания на карту.

---

## 1. Требования к платформе (почему именно так)

| # | Требование | Обоснование |
|---|---|---|
| 1 | ≥2 физических слота x16, **без райзеров** | MODS видит «1 линию вместо 16» через райзер и вешается; P2P/Gen2 тоже по прямым слотам |
| 2 | **CSM/Legacy boot** в BIOS | Диагностическая флешка MATS: в UEFI — ложные ошибки по всем каналам (FIELD_GUIDE §4); тестировать в Legacy |
| 3 | **Above 4G Decoding** (обязательно) + Resizable BAR Auto | Payload буферы V67 живут >4 ГБ (efi-unlock docs); ReBAR для BAR1 |
| 4 | IOMMU + большие MMIO-окна | `intel_iommu=on iommu=pt pci=realloc,hpmemsize=8G` (p2p-setup.sh) |
| 5 | Secure Boot off | Патченный модуль/диагностика |
| 6 | Дисплей-адаптер НЕ от тестируемой карты | CMP без видеовыходов: GT 710/1030 (~1–2 т.₽) или CPU с iGPU |
| 7 | БП ≥1000 Вт gold, **отдельные кабели 8-pin** | 90HX: 2×8-pin на карту, лимит 250 Вт; пик системы ~750–800 Вт на 2 карты |
| 8 | RAM ≥64 ГБ | llama.cpp offload-сценарии, `--no-kv-offload`, хост-обработка |
| 9 | Продув корпуса | Карты blower-типа; горячий выхлоп памяти GDDR6X |
| 10 | NVMe 1–2 ТБ | Модели: Qwen3.8-27B Q4 ≈ 17 ГБ; HF-кэш растёт быстро |

## 2. Конфигурация A — бюджетная (рекомендую): X99 + Xeon E5

**«Классика дешёвого CUDA-сервера»**, по пути автора Habr-серии (у него два Xeon).

| Компонент | Что брать | Ориентир цены (б/у, ₽) |
|---|---|---|
| Плата + CPU | **Huananzhi/Atermiter X99 (T8/F8/CH8)** + **Xeon E5-2680 v4** (14C/28T) | 4 200–7 000 (комплекты на Avito) |
| RAM | 4×16 ГБ **DDR4 REG ECC 2133–2400** (серверная — копейки) | 5 000–8 000 (64 ГБ) |
| Дисплей | GT 710 / GT 1030 (пассив) | 1 000–2 000 |
| NVMe | 1–2 ТБ | 4 000–6 000 |
| БП | 1000–1200 Вт gold (Seasonic/Corsair/середина), 6+ кабелей 8-pin | 6 000–9 000 |
| Корпус/охлаждение | 4U серверный (Ali «6 GPU») или открытый стенд + вертушки | 3 000–6 000 |
| **Итого хост без карт** | | **~25 000–38 000** |

Почему X99: 40 линий PCIe Gen3 — обе карты по **физическому x16** без чипсета;
CSM есть; Above 4G есть; DDR4 RECC бесплатная по нынешним меркам; Linux 6.x
работает (стек cmp90hx-unlock проверен на ядре 6.12). Минус: прожорливый простой
(~100 Вт платформа) и возраст — но для 24/7 LLM-бокса это норма.

## 3. Конфигурация B — тихая/современная (если вторая карта встанет через чипсет)

* **Ryzen 5 5600 + B550** (слот x16 CPU + второй x16-слот через чипсет x4):
  вторая карта получит x4 через чипсет — **достаточно для PP (layer split)**,
  недостаточно для TP; CSM есть не на всех B550 — проверять до покупки.
* **i3-12100 (iGPU UHD 730) + B660**: дисплей встроенный (не нужен GT 710),
  CSM у большинства плат есть; обе карты — CPU-слот + чипсет.
* Ориентир: 20 000–30 000 ₽ с 32–64 ГБ DDR4. Компромисс: меньше слотов под
  3-ю/4-ю карту.

## 4. Конфигурация C — с запасом на 3–4 карты

Supermicro X11SPi-TF / ASRock Rack EPXCL1925 + Xeon Gold 6132/6142 (LGA3647):
48+ линий, 3–4 слота x16, IPMI (удобно управлять headless-сервером с CMP-картами).
Ориентир 30 000–45 000 ₽. Имеет смысл, если план — 4 карты и 40–50 ГБ VRAM.

## 5. Чек-лист настройки BIOS/системы

```text
[ ] Secure Boot: Disabled
[ ] Above 4G Decoding: Enabled          (критично для V67)
[ ] Resizable BAR: Auto/Enabled
[ ] CSM: Enabled                        (для MATS-флешки; в работе можно UEFI)
[ ] Загрузка диагностической флешки: пункт БЕЗ префикса "UEFI:"
[ ] Первая загрузка Linux: sudo ./install-unlock.sh → check.sh
[ ] PCIe-ширина карт: check.sh печатает current/max — если x4 → конденсаторы 220 нФ
[ ] P2P (2 карты): sudo ./p2p-setup.sh → перезагрузка → verify
[ ] Power limit: sudo ./power.sh persist 200  (см. оговорку в power.sh)
```

## 6. Что НЕ покупать

* **Райзеры** (USB-райзеры майнинговые) — MODS и ширина линка ломаются
* **Intel F-серии без дискретки-дисплея** — нечем показать BIOS/MODS
* Платы **без CSM** для основного стенда диагностики
* БП <850 Вт или с петлями кабелей вместо отдельных 8-pin
* X99-платы с **только одним слотом x16** (частая экономия у Atermiter) —
  смотреть фото слотов до покупки: нужно ≥2 полноразмерных x16
